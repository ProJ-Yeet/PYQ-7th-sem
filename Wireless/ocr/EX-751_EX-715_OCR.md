# Wireless Communication — OCR archive

Verbatim transcription of every scanned Wireless Communication question paper
held in this project. Two courses share one syllabus and are combined here:

- **EX 715** — Wireless Communication, BEI, Year/Part IV/I (the current paper)
- **EX 751** — Wireless Communication, BEX, Year/Part IV/II (the older paper)

|---|---|---|
| `New PYQ/WC.pdf` | 23 | pp.1–7 EX715 (BEI), pp.8–23 EX751 (BEX). p2 BLANK. **p16 is not a Wireless paper** — see defects. |
| `New PYQ/wc4.1bei.pdf` | 7 | byte-identical to `WC.pdf` pp.1–7 (the BEI slice). Nothing unique. |
| `Wireless/EX-715_81-70.pdf` | 15 | the OLD scan. Every paper is also in `WC.pdf` EXCEPT p8 = **2073 Bhadra**, so the old scan must be kept. |

Transcribed 2026-08-25 by rendering each page at `fitz.Matrix(2.4,2.4)` grayscale
(~1430×2020 px) and reading the image; the embedded text layer of `WC.pdf` is
garbage OCR ("TRIBHUVAN I\"]NiV ERSITY") and was used only as a page index.

Typos are reproduced **as printed** ("Okumara", "forth generation", "RACK
receiver", "near for effect", "speed signal", "12.8 MHz fir every simplex band",
"1200 sectoring", "Ic) 60°"). Do not silently correct them — the `.tex`
documents quote these statements.

## Defects in the sources — recorded, not corrected

1. **`WC.pdf` p16 is the wrong subject.** The page sits where 2073 Bhadra
   Wireless would go, but its subject line reads *Digital Signal Processing
   (EX 753)* and every question is DSP (convolution, Z-transform, DFT, bilinear
   transformation). It is the same paper already transcribed in
   `DSAP/ocr/CT-704_EX-753_OCR.md` (p40 of that scan). The genuine
   **2073 Bhadra Wireless** paper survives only on p8 of the old scan.

2. **`WC.pdf` p9 (2079 Chaitra) prints `Programme: BEI`** while carrying
   subject code EX 751 and Year/Part IV/II — i.e. the BEX paper. Verified by
   re-cropping the header at Matrix(5.0). Treated as BEX throughout.

3. **2073 Magh Q2 has no data.** The paper reads only "Determine: a) the cell
   cluster size b) the number of cell clusters in the service area c) the
   maximum number of users in service area at any instant [6]" — no cell count,
   area, channel count or reuse factor is printed. Present in *both* scans, so
   it is the paper's own defect, not a scanning loss.

4. **`WC.pdf` p17 (2073 Magh) is clipped at the foot** — the Q8 short-notes list
   stops after "a) WiMAX". The old scan p9 has the full list
   (a WiMAX, b Handover, c BPSK against QPSK modulation).

5. **2082 Bhadra Q3 b** prints "an EIRP oh 1 kW" (for "of").

5a. **2082 Baishakh Q4** prints "the median path loss sing Okumura's model"
   (for "using"). Verified by eye at Matrix(4.0); it is the paper's own typo.

5b. **`WC.pdf` p2 was archived as BLANK until 2026-09-13.** It is the whole
   **2082 Baishakh** paper. Every other page of `WC.pdf` carries a machine text
   layer, so a page returning zero characters read as blank — but p2 is simply a
   dark scan the embedded OCR failed on: ~5.0 % dark pixels at 36 dpi against
   ~1.4 % for a normal question page. `tools/ocr_page.py` reads it cleanly and the
   marks reconcile to exactly 80. Never infer "blank" from an empty text layer;
   measure ink coverage first. `DSAP.pdf` p2 had the identical defect.

6. **2076 Bhadra Q7** prints "near for effect" for "near-far effect"; the same
   typo recurs in 2075 Bhadra Q10.

7. **2070 Magh Q10(c) was missing from this archive** until 2026-08-27. The
   short-notes list is marked `[4×3]` but only two items had been transcribed.
   Recovered from the text layer of
   `Wireless/EX-751_70-80__EX-715_79-82.pdf` p23: the third item is
   **"Viterbi decoding algorithm"**. It is now added above. Consequence for the
   notes: **2070 Magh has no WiMAX question**, contrary to the tag in
   `Wireless_Sorted_PYQ_Detailed_70-82.tex` (see the Chapter 8 defect note in
   `NOTES-BUILD-PROGRESS.md`).
