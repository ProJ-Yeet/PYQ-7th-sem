\subjecttitle{ADVANCED FPGA AND EMBEDDED DESIGN}{EX 72506}{3}{1}{1.5}{IV}{I}

\cobjectives
  To provide FPGA Design fundamentals to advance concepts and also understand the embedded design flow and approaches in FPGA targeted for real world applications. Understanding latest methodologies and technologies in FPGA, Embedded and VLSI
  design.
  \VS

\begin{enumerate}
  \item \textbf{FPGA Fundamentals \hfill (5 hours)}
    \begin{enumerate}
      \item EFPGA overview and its evolution
      \item General FPGA Building Blocks: LUT, FF, DSP, BRAM, I/O, clocks etc.
      \item FPGA Architectures: general architecture, vendor specific architecture summary
      \item Recent developments in FPGA Architecture: heterogeneous architectures
      \item FPGA Architecture targeted for cloud and edge platforms
      \item FPGA Design Flow - summary
    \end{enumerate}
    \vs

  \item \textbf{CFPGA logical components, architecture and interfaces \hfill (3 hours)}
    \begin{enumerate}
      \item Logical Interconnection and Routing architectures in FPGA
      \item AXI Interface Bus protocol
      \item High speed Interfaces and usage of those interfaces
      \item  High speed bus protocols in FPGA : USB, PCIe, Ethernet, MIPI etc.
      \item Embedded SoC/MPSoC architectures detail and interfaces
    \end{enumerate}
    \vs

  \item \textbf{Digital design, simulation and verification with RTL (VHDL/Verilog) (6 hours)}
    \begin{enumerate}
      \item Verilog HDL overview- syntax, semantics, datatypes, primitives, etc.
      \item Behavioral versus structural design modeling
      \item Logical component design with RTL/Verilog and performing simulation: combinational/sequential blocks, FSM, ALU, processor and DSP algorithms
      \item Verification approaches on RTL
      \item RTL design methodologies for FPGA and VLSI Design
      \item Design optimization on RTL for FPGA and VLSI Design
    \end{enumerate}
    \vs

  \item \textbf{Advance RTL design approaches for FPGA \hfill (4 hours)}
    \begin{enumerate}
      \item Advance RTL design for latency critical and resource critical designs- overview
      \item Resource, latency, clock and power optimization methodologies
      \item Considerations/approaches for Implementing RTL design in a real-world scenario
    \end{enumerate}
    \vs

  \item \textbf{VLSI Design and Verification \hfill (6 hours)}
    \begin{enumerate}
      \item VLSI Design, IC technology, CAD tools on VLSI- overview
      \item VLSI Design flow, design styles and verification methodologies
      \item CMOS Circuit and Logic Design
      \item Design and analysis of the CMOS inverter
      \item Analog/ Mixed Mode VLSI design concepts
    \end{enumerate}
    \vs
    
  \item \textbf{Embedded Design methodology on FPGA \hfill (4 hours)}
    \begin{enumerate}
      \item Embedded Design overview
      \item RTL and HLS design approaches in Embedded design
      \item SoC/MPSoC FPGAS and design approaches with AMD Xilinx tools
    \end{enumerate}
    \vs
    
  \item \textbf{Embedded C programming for SoC FPGA \hfill (6 hours)}
    \begin{enumerate}
      \item Embedded C programming - overview
      \item Microblaze, ARM processor and RISC based system on chip platforms
      \item Writing applications for embedded SoC and its approaches
      \item Embedded application optimization for latency: multi-threading and multi-processing
    \end{enumerate}
    \vs

  \item \textbf{Embedded Operating Systems and usage on SoC FPGAs \hfill (4 hours)}
    \begin{enumerate}
      \item Embedded OS: Baremetal, FreeRTOS, and Linux based OS
      \item FPGA and Embedded design integration with AMD Xilinx SoC/MPSoC FPGA
    \end{enumerate}
    \vs

  \item \textbf{Advanced design, methodologies and applications of FPGA \hfill (7 hours)}
    \begin{enumerate}
      \item Recent FPGA developments, architectures and its implications
      \item Application level design, simulation and implementation of DSP, Signal Processing and Telecommunications algorithms in FPGA - Design aspects and methods
      \item RISC processor architecture design flow in Verilog
      \item CMOS component design and analysis
      \item Hardware/software co-design, accelerator design with FPGA and integrating with Embedded flow.
      \item Approaches of algorithms implementation and offloading in FPGA
    \end{enumerate}
    \vs
\end{enumerate}

\Vs
\noindent \textbf{Practical:}
  \begin{enumerate}[label=\arabic*.]
    \item Logical design implementation on FPGA with Verilog. Using Arty A7 and Zybo Board.
    \item Advanced RTL/Verilog Lab with small scale processor design (8 bit), FFT , DFT, DCT, Convolution and OFDM based design, simulation and implementation in FPGA.
    \item RISC-V (ISA) based implementation in RTL/Verilog.
    \item Introductory Lab on VLSI design/verification (CAD tool overview, logical gate design, CMOS component design and analysis).
    \item Handling GPIO on FPGA platform via Verilog. Using Xilinx Arty A7 and Zybo Board.
    \item Embedded FPGA Design Lab- creating IP based design and Embedded C based application with AMD Xilinx VIVADO/Vitis and FPGA
    \item Embedded design for Baremetal, FreeRTOS and Linux based applications
    \item Creating custom accelerator for computer vision and CNN, integrate it with SoC embedded design flow.
    \item Using machine learning acceleration approaches in FPGA. Designing with AMD Xilinx platform for Machine Learning Acceleration
  \end{enumerate}
