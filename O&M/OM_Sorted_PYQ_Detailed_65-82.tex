  \item Regular exam = \bo{bold}, Back exam = regular font. A header printing ``Regular / Back'' in one box counts as Regular, so \bo{75 Ch} and the whole 2065--2068 block are bold.
  \item Months: Ba = Baishakh, Asa = Ashad, Shr = Shrawan, Bh = Bhadra, Ash = Ashwin, Ka = Kartik, Po = Poush, Ma = Magh, Ch = Chaitra.

  \item 2072 Kartik prints no marks --- its rubric says all questions carry equal marks, so each is 8. 2075 Ashwin prints no marks against Q5 alone.
  \item Keywords: (I) = Importance/Need/Significance, (+) = Advantage, (-) = Disadvantage, +Fig = Figure/Diagram, +Eg = Example, Vs = Compare/Differentiate.
